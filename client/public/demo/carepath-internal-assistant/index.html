Ask something staff actually ask

Pick a question above. Every answer names the document, the revision number and the date it was approved.

Why version conflicts are the whole problem

The assistant's most useful behaviour isn't answering — it's refusing to answer cleanly when two documents disagree, and telling a named person about it.

SituationWhat it does
One current documentAnswers, with citation and approval date
Two versions foundShows both, flags the conflict, routes to the policy owner
Document older than 12 monthsAnswers, but marks the age in the reply
Nothing foundSays so and opens a request to the governance inbox

How it's built

Indexed, not trained

The document set is searched at question time, so a superseded file stops being quoted the day it's archived.

Citation is mandatory

An answer without a source doesn't render. There's no fallback to general knowledge.

Read-only by design

It can't edit policy, approve anything, or answer clinical questions. It points at documents.

Concept workflow. No live deployment, so no time-saved figures are claimed.
