A clothing label with a catalogue account. Every post was a product, which teaches an audience to scroll. The interesting material — dye runs, pattern cutting, the people who make the clothes — was never posted.

How to use this page. Toggle a pillar on the left to see how the grid composes without it. Select any tile for the crop rule, the caption framework and what that post is actually for.

Pillars

One month, batched

Nine posts a month, not thirty. Product and point-of-view alternate; process fills the gap between them. Everything is shot on two days, which is the only reason the rotation survives a busy month.

Concept system. It has not been run on a live account, so there is no reach or engagement data to quote — the deliverable here is the operating system, not a set of results.
