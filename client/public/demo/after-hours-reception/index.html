The enquiries that arrive after you lock up.

Most dental enquiries land between 6pm and midnight. By morning the caller has booked with whoever answered first. Voicemail doesn't fix this — people don't leave them. This assistant answers logistics, captures the reason for contact, books a call-back, and never pretends to be a clinician.

Where it stops

In healthcare, an assistant that appears human is a liability. This one is deliberately plain.

  • Refuses clinical questions outright"I can't advise on pain. If it's severe or you have facial swelling, call 111 or go to A&E."
  • No avatar, no personality, no fake typingPlain text on white. It reads like a form that talks back, because that's what it is.
  • Says when it doesn't knowUnanswered questions become a call-back with the question attached, not a guess.
  • States what it is on every screenThe "not a clinician" line is fixed, not buried in a disclaimer.

How it's built

Bounded knowledge base

Hours, location, fees, insurers, parking. Nothing else is in scope, so nothing else can be invented.

Refusal designed first

The clinical-advice boundary was written before the helpful answers were.

Real calendar, real slots

Call-backs are booked against front-desk availability, so nobody is promised a time that doesn't exist.

Concept workflow. No live deployment, so there is no capture-rate data to quote. The designed benefit is that an out-of-hours enquiry becomes a scheduled call-back instead of a missed call.
